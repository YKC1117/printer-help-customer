# 標籤機簡易排查｜客戶版

這是個人工作上提供給客戶使用的標籤機簡易排查工具，**不是萬里資訊官方網站或正式客服系統**。

客戶版只提供安全、基本的故障排除。深入設定、拆機、量測、零件判斷、服務指令與維修內容不放在此公開專案。

## 目前版本

- 客戶版：`v1.10.3`
- 技術：原生 HTML / CSS / JavaScript
- 部署：GitHub Pages
- 後端：無
- 客戶資料上傳／蒐集：無

## 專案架構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 客戶操作頁面、8 個引導式問題分類與 1 個「不確定」直接回報分類 |
| `styles.css` | 共用版面、問題卡片、排查流程、分支與摘要的主要樣式 |
| `enhancements.css` | 後續 UI 增強：不確定問題、返回按鈕、字數提示、頁尾提醒 |
| `data.js` | 品牌與型號資料 |
| `flows.js` | 各問題分類的安全排查步驟與建議照片清單 |
| `app.js` | 品牌篩選、流程狀態、connect 分支、摘要複製、不確定欄位驗證與 `selfCheck()` |

## 操作邏輯

- 「品牌／型號」目前用來協助回報與辨識設備；**不會切換不同型號專屬排查流程**。
- 「問題分類」決定客戶看到的排查內容。
- 8 個標準分類採一次顯示一個步驟的引導方式，可前進、返回上一步或標記已恢復正常。
- `connect` 額外先判斷印表機本身是否已有錯誤，再決定是否進入電腦端基本排查。
- 「找不到符合的問題／不確定」不提供進階維修，只收集簡短現象描述與建議照片。
- 排查結果只在瀏覽器當下產生並供複製；目前沒有後端、資料庫或使用紀錄回傳。

## 客戶版安全邊界

1. 客戶只做低風險、可逆的基本檢查。
2. 不提供拆機、內部配線、零件更換、進階維修參數或服務指令。
3. 切刀卡死、異味、冒煙、異常高溫等情況會要求停止操作。
4. 仍異常時，以整理排查結果與照片回傳為主，不把工程師版內容下放到 Public repository。

## 維護與驗收

每次修改至少確認：

- 品牌選擇與型號篩選正常。
- 9 張問題卡片皆能開啟正確區塊。
- 8 個標準排查流程可正常前進、返回與完成。
- 「問題已排除」完成卡片只在客戶按下恢復正常後顯示，未完成排查時不得預先出現。
- `connect` 分支可正常進入 Ready 流程、返回分支題，以及處理其他錯誤的停止畫面。
- 「不確定」分類空白時會提示，輸入後可整理摘要，500 字計數正常。
- 摘要與複製功能正常。
- 手機版與桌機版沒有明顯排版異常。
- `app.js` 的 `selfCheck()` 不應出現 `console.warn`。
- 頁面版本號與靜態資源 cache query 同步。

## `selfCheck()`

`app.js` 內建輕量完整性檢查，會核對品牌數、產品數、問題卡片、標準／直接回報分類、connect 分支標記、上一步按鈕、connect 返回按鈕、不確定欄位提示與字數計數器。

它不是完整自動化測試，但可以在日後修改時快速發現常見的漏改或 DOM 數量不一致。
