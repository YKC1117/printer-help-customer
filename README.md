# 標籤機簡易排查｜客戶版

這是個人工作上提供給客戶使用的標籤機簡易排查工具，不是萬里資訊官方網站或正式客服系統。

客戶版只提供安全、基本的故障排除。深入設定、拆機、量測、零件判斷與維修內容不放在此公開專案。

## 檔案
- `index.html`：客戶操作頁面與基本排查內容
- `styles.css`：主要版面樣式
- `enhancements.css`：後續新增的介面樣式與操作提示
- `data.js`：品牌／型號資料
- `flows.js`：各分類排查步驟與建議照片清單
- `app.js`：品牌篩選、排查流程、摘要、複製與自我檢查邏輯

## 維護原則
1. 客戶只做低風險基本排查。
2. 仍異常時停止調整並把排查結果、照片傳回處理。
3. 工程師版內容不得加入本 Public repository。
4. 每次正式改版同步更新頁面版本號與快取版本。
